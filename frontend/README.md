# ManFast — Frontend

Aplicația React (Vite) pentru platforma ManFast.

Documentația completă (instalare, configurare, API, demo): **[README din rădăcina proiectului](../README.md)**.

## Comenzi rapide

```bash
cp .env.example .env
npm install
npm run dev
```

URL: `http://localhost:5173`

Variabilă necesară în `.env`:

```env
VITE_API_URL=http://localhost:5000
```
